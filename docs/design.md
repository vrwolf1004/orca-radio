# 디자인

옛날 라디오 모양의 패널입니다. 나무 캐비닛, 황동 테두리 눈금판, 스피커 그릴, 조작 버튼으로 구성합니다.

## 화면 구성 (위에서 아래로)

1. **상단**: 브랜드 "ORCA", 대역 표시 "AM·FM"
2. **눈금판**: 대역 눈금(AM/FM/SW), 빨간 바늘, 방송국 이름
3. **스피커 그릴**: 점 패턴의 어두운 판
4. **조작 버튼**: 이전, 재생(강조), 정지, 다음
5. **볼륨**: "VOL" 라벨과 슬라이더
6. **상태 문구**: 대기 중, 연결 중, 재생 중, 버퍼링, 정지, 오류

## 색

| 용도 | 색 |
| --- | --- |
| 나무 (밝은 면/어두운 면) | `#5a3a22` / `#3e2614` |
| 황동 (테두리, 라벨) | `#c9a25a` |
| 눈금판 크림색 | `#f3e6c4` |
| 바늘 | `#b3261e` |
| 상태 글자 (호박색) | `#ffb24a` |

색은 `panel/style.css`의 `:root` 변수로 정의되어 있습니다.

## 캡처 기준

- 패널 폭은 약 335px로 봅니다.
- 세로 스크롤바가 보이지 않는 것이 목표입니다. 현재는 보입니다.

## 남은 디자인 과제

- 나무결을 더 진하게 하거나 금속 장식을 더할지 결정 필요
- 재생 중 바늘이 움직이는 표현은 아직 없음

## 디자인 비교 (A / B / C)

기능과 게이지 형태는 세 디자인이 같고, 색과 버튼, 패널 질감만 다르다.

| 디자인 | 콘셉트 | 파일 | 캡처 |
| --- | --- | --- | --- |
| A | 1980~90년대 목재 탁상 FM (기본) | `panel/style.css` | `design-shots/design-a.png` |
| B | 클래식 하이파이: 월넛 + 브러시드 골드, 작은 기계식 키 | `panel/themes/b.css` | `design-shots/design-b.png` |
| C | 레트로 테크놀로지: 차콜 외관, 앰버 표시등, 둥근 CHANNEL 셀렉터 | `panel/themes/c.css` | `design-shots/design-c.png` |

**전환 방법**: `panel/index.html` 의 `<head>` 에서 해당 줄의 주석(`<!-- -->`)을 풀면 된다. 여러 줄을 동시에 풀지 않는다. A 는 줄을 모두 주석으로 둔다.

- B: `<link rel="stylesheet" href="themes/b.css">`
- C: `<link rel="stylesheet" href="themes/c.css">`

**주의**: 테마 파일은 `style.css` 뒤에 읽혀 덮어쓴다. 게이지 형태와 볼륨 형태는 바꾸지 않았다.
