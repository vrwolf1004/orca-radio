# 디자인

옛날 라디오 모양의 패널입니다. 나무 캐비닛, 황동 테두리 눈금판, 스피커 그릴, 원형 조작 버튼으로 구성합니다.

## 화면 구성 (위에서 아래로)

1. **상단**: 브랜드 "ORCA", 오른쪽 "Radio"
2. **다이얼 창**: 89.1 ~ 108.0 MHz 눈금, 빨간 바늘, 방송 이름, 오른쪽 아래 ON AIR 램프
3. **T / CH 버튼**: 황동 원형 버튼 2개. T 는 디자인 전환, CH 는 채널 서랍
4. **스피커 그릴**: 점 패턴의 어두운 판. 오른쪽 위에 전원 표시등이 있고 재생 중 껌뻑임
5. **조작 버튼 4개**: 이전 채널(◀◀), 재생(▶), 정지(■), 다음 채널(▶▶). 52px 원형, 이중 황동 링, Lucide 아이콘
6. **볼륨**: "VOL" 라벨과 슬라이더
7. **채널 서랍**(CH 로 열림): 본체 아래로 내려오는 방송 목록

## 상태 표시

- **재생 중**(`.is-playing`): 바늘이 빛나고, 눈금판이 살짝 깜빡이고, ON AIR 램프가 켜지고, PLAY 링이 앰버색으로 빛납니다.
- **정지**: 모두 꺼진 상태입니다. 상태 문구는 화면에 보이지 않고 화면 낭독기에만 읽힙니다.

## 버튼 (하단 조작)

- 모양: 원형 베이클라이트, 지름 52px, 황동 링 두 겹(이중 링), 살짝 볼록한 그림자
- 아이콘: Lucide 선 아이콘, 선 굵기 1.5px, 크기 20px, 아이보리색
- 누르면 2px 안으로 들어가고 안쪽 그림자가 생깁니다.

## 디자인 비교 (A / B / C)

기능과 게이지 형태는 세 디자인이 같고, 색과 버튼, 패널 질감만 다릅니다.

| 디자인 | 콘셉트 | 파일 | 캡처 |
| --- | --- | --- | --- |
| A | 1980~90년대 목재 탁상 FM (기본) | `panel/style.css` | `design-shots/design-a-final.png` |
| B | 클래식 하이파이: 월넛 + 브러시드 골드 | `panel/themes/b.css` | `design-shots/design-b-final.png` |
| C | 레트로 테크놀로지: 차콜 외관, 앰버 표시등 | `panel/themes/c.css` | `design-shots/design-c-final.png` |

`T` 버튼으로 A → B → C 순서로 바꿉니다. 고른 디자인은 기억합니다.

## 캡처 기준

- 패널 폭은 사이드바 폭에 따라 달라집니다(약 300~500px).
- 목록용 이미지(`docs/store/`)는 WebP로, cover 1600×1000, 스크린샷 2560×1600 기준입니다. 캡처를 확대해 만든 합성 이미지이므로, 실제 큰 화면으로 다시 찍으면 더 선명합니다.

## 남은 디자인 과제

- 테마 B, C에서 원형 버튼의 색과 질감 확인
- 주파수 눈금 숫자가 바늘과 겹치는 부분 정리
- 스토어 이미지를 실제 캡처로 교체
